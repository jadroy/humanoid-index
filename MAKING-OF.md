# Building humanoid-index.com

A visual index of humanoid robots. Four months, 237 commits, seven branches, three dead-end design experiments. This is how it got made.

## The premise

The site exists because there isn't a good one. Boston Dynamics has a YouTube channel. 1X has a press kit. The humanoid robotics field went from "lab curiosity" to "you can preorder one for sixteen thousand dollars" without ever getting a place to look at all of it side by side. So that became the brief — a single page where you could scroll through the field, compare any two, and casually learn the shape of it.

The harder constraint was the second goal: make it feel like the web could.

> "this is first n foremost supposed to be a cool web experience n casually informative"
> — Apr 20

## Act 1 — Exploration

**Jan 10, 2026** — Initial commit. Seven robots, a sidebar, detail routes at `/robot/[id]`. A clean Next.js skeleton with no opinions about how navigation should feel.

Within two weeks, the two ideas that would define the site appeared in the same commit: a compare panel (still a modal at this point) and hover-driven card animations. The chatbot landed three days later. The intended shape was visible — AI guide plus scroll experience — but none of the pieces were any good yet.

**Jan 20** — A one-day detour: the `horizontal-layout-experiment` branch. Wheel-deltaY hijacked into horizontal scroll. Bottom-bar control strip. Killed within six hours; buried by the next day's chatbot work.

**Feb 14-16** — Three days of `carousel-centric` branch. Black-and-white "stripped technical" aesthetic. A 360° elliptical card path where every robot was always visible (tiny and faded at the back). A `SmashPicker.tsx` (344 lines) that let users pick robots in a Super Smash Bros. roster grid, complete with spotlight keyboard navigation. Video emote states triggered by spacebar.

Eighteen commits in fifty hours, then nothing. The robots had gained emote slots. The site had drifted from index into toy.

**Mar 26** — The "everything is an experiment" pivot. Six switchable layout modes ship in one commit: Full Bleed, Rolodex, Filmstrip, Arc, Spread, Orbit. The product had become a layout explorer. The actual product was missing.

## Act 2 — Physics and focus

**Mar 29** — The big subtraction. All six layout modes collapse into one. 2,045 lines deleted, 434 added. A spring-driven scroll browser is what remains. Everything afterward is built on this interaction vocabulary.

A parallel branch — `wheel-layout-experiment` — ran for the next month. 88 commits, mostly additive experiments on top of the arc system: a `LabelWheel.tsx` with quadratic-curve labels above and below the active one; an `ArcYearMarker` for a timeline overlay; five weights of a custom pixel font called GeistPixel for a flip-clock year display. The core arc survived into v2. Most of the decoration did not.

> "Single year label tucks beside the active arc name, only flips (3D rotateX) when the active item's year actually changes rather than on every hover or frame."
> — commit body, Apr 8

That level of care for a single decorative element is why the branch ran for a month.

**Apr 5** — The intro animation lands. Logo fades in, ring draws around it, content expands outward. First moment the site has a face.

**Apr 10** — The performance pivot that mattered. The arc wheel gets decoupled from React state. Spring values feed an imperative subscription instead of triggering re-renders. The site stops fighting the framework.

> "hmm, i care lots about smoothness/no lag, can we prioritize here?"
> — Apr 15

**Apr 15** — Deeplinks. `?h=<id>` and `?compare=<a>,<b>` hydrate on mount.

> "LES GOO, lets do ittt"

OG cards land the same week. Satori-rendered side-by-side compare layouts via `/api/og/[id]/route.ts`.

> "OOOOOH not baddd"
> — first time seeing the compare OG render

The embed widget shipped the same day. Three distribution surfaces in one week: direct link, deeplink with metadata, and `<iframe src="/embed/1">`.

**Apr 16** — The interaction language gets named.

> "there's still a lot of unnecessary motion/dissappearing/etc, i want this to feel as smooth as a physical crown/watch"

**Apr 20** — The strategic moment. After a long session reading the codebase end to end:

> "waiiit some of this stuff is SICC, i think the sharing links especially seem super helpful for spreading this / making this a main reference site"

**Apr 24** — A new aesthetic vocabulary emerges in the hover interactions: 420ms linger, 700ms ease-out fade, dissolves into mist.

> "want it to feel hella light to the touch n almost ethereal"

**Apr 26-28** — The AI content layer. 351 robot-pair blurbs pre-generated via Haiku for compare mode. Per-robot descriptions generated by what was assumed to be Opus.

It wasn't.

> "LOOOL i thought i was using opus for the last couple days, have been using sonnet across multiple chats... you're cool but meant to use a little more firepower"
> — Apr 28

Sonnet's G1 description had read: *"moves like a question worth asking."*

> "LOL bruh g1 sounds so corny i cant lie, the others were fine so far from what ive seen but this reads like a childrens book"

After the model swap, Neo came back with: *"A bipedal humanoid built for the home. Light, quick, and safe around people."*

> "incredible, these are solid, neos is incredible - lets note this language"

That sentence is now the voice guide for every description on the site.

**Apr 27** — The chatbot from January returns, now backed by a real Anthropic route. Haiku, JSON-only schema, per-IP rate limiting, prompt caching. The chat doesn't just talk — it drives the carousel. A `show` action jumps to a robot; a `compare` action enters compare mode. The AI surface goes from decorative to functional.

## Act 3 — Polish toward launch

**May 5** — A z-index war. Clicking the price pill triggers the status pill above it. The fix, found by a parallel Claude session in another chat:

> "Restored zIndex: 11 on accordion wrapper (lines 1478, 2020). It was removed during an unrelated shadow-debugging session and never restored..."

Roy had become his own project manager between parallel agents.

**May 6** — The Memo 3D spin viewer. Thirty WebP frames for a full 360° turntable. Robots become objects you can inspect, not just compare.

**May 7** — The rewrite trap conversation.

> "had the thought that mayyy wanna start the codebase from scratch since we know what we want n can maybe architect it better but idk may be OC"

The codebase had four months of embedded tuning. A rewrite would have thrown all of it out to land in the same place in eight weeks. Decision: don't.

The same day, the design system philosophy got named:

> "i dont want to spend so much time on a highly crafted design system, i want it to be simple and obvious yet still feel well, cus i wanna focus on the value being provided and having like a breadth of cool projects : )"

**May 8** — Launch prep. Chat hidden, Memo 3D gated, the dev options menu replaced with a "Crafted by Roy Jad" credit. The site trims back to its strongest surface.

A new idea, sketched mid-session:

> "maybe have humanoid index in the center (no container) and on hover it flips to 'share' sort of like one of those flip clocks you know what im sayin?"

The share button is now a flip-clock.

**May 12** — A morning of taste calibration. The drag pill that follows the cursor:

> "should trail a little closer, land on the cursor, but the bottom edge of it" → "ok now the pill is too far below the cursor, shoudnt be a gap when it lands" → "still" → "ok, lets make it trail a little slowre, and land 4px"

Stats column font size: 14 → 13 → 12.5 → 12.5. Confirmed.

The environment fade for the background photo:

> "lets come back to a simpler fade in for the environment, feel like we went the wrong way (don't undo code, just change it back)"

**May 13** — The current aesthetic locks in. The stats column becomes a stack of labeled cards. A `tags?: string[]` field lands on each humanoid — hand-curated factual chips like "Amazon facilities," "DARPA pioneer," "$16K affordable."

> "wonderful, exactly what i was lookin for"

The same day, the case study began.

> "YOO, just had an idea, feelin a bit lazy to create a case study/writeup around this proj"

## What the site is

A visual index of humanoid robots that you scroll through with a spring. Compare any pair side by side. Each robot has a description in a voice the site spent two weeks finding. There are descriptor tags. There are share links and embeds. There is a chatbot that can drive the page. There is a 3D spin of the one robot interesting enough to model.

The site started as a sidebar with seven robots and a detail route. It became this through subtraction: of layout modes, of decoration, of features that drifted from index into toy. The defining moments were almost all reversals — kill the horizontal scroll, kill the SmashPicker, kill the elliptical carousel, kill the six layout options, kill the rewrite, kill the dark contrast, kill the children's book voice.

What's left is the part that felt right.
